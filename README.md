# TWEET 🐦

A Twitter-like social media web application built using **Django**, allowing users to create accounts, post tweets, and interact with content in a simple and intuitive interface.

---

## 🚀 Features

- User authentication (Login / Register / Logout)
- Create and delete tweets
- User-specific tweet feeds
- Profile-based content rendering
- Secure backend with Django ORM
- Clean and responsive UI

---

## 🛠 Tech Stack

- **Backend:** Django
- **Frontend:** HTML, CSS, Django Templates
- **Database:** SQLite (default)
- **Authentication:** Django Auth System
